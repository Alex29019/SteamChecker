# 🎮 Steam Profile Checker

Легальный чекер публичной информации Steam-профиля через XML API.

## Что проверяет
- ✅ Статус аккаунта (онлайн/оффлайн/отошёл)
- ✅ VAC-баны
- ✅ Дата регистрации
- ✅ Аватар и никнейм

## Деплой на GitHub Pages

1. Создай репозиторий `steam-checker`
2. Загрузи все 4 файла в корень
3. Settings → Pages → Source: `main` branch → `/ (root)`
4. Через 1-2 минуты сайт будет по адресу:  
   `https://твой-логин.github.io/steam-checker/`

## Как пользоваться
1. Зайди на https://steamid.io/
2. Вставь ссылку на свой профиль
3. Скопируй **SteamID64** (17 цифр)
4. Вставь в поле на сайте → "Проверить"

Или просто вставь полную ссылку на профиль Steam.

## ⚠️ Важно
- Работает только с **публичными** профилями
- Не использует пароли — только публичные данные
- Использует CORS-прокси allorigins.win

## Технологии
- HTML5 + CSS3 (анимации, glassmorphism)
- Vanilla JS (без фреймворков)
- CORS-прокси: allorigins.win
